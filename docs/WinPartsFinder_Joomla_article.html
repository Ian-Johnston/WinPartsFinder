WinPartsFinder
Electronic component supplier search for Windows.

When designing PCBs, or repairing test equipment, old or new, I spend far too long fishing around the usual parts suppliers' websites to see who has a part, how many, and at what price, and usually with multiple tabs open. WinPartsFinder does that legwork for you: type a part number or a few keywords, press Enter, and it searches the big suppliers all at once and lists stock, prices, price breaks, minimum order quantity, lifecycle status and datasheets side by side in one grid.

WinPartsFinder is strictly for non-commercial, non-business use only, please see the Licence & Usage statement at the foot of this page.

Written in VB.NET using Visual Studio 2022 and .NET Framework 4.8 (built into Windows 10 & 11, so there is nothing extra to install). For Win7 you will need to install .NET 4.8 first.
Live data comes from the suppliers' own free APIs (Mouser, DigiKey, element14 and TME) and suppliers without a public API are searched with one click on their own website.

SUPPLIERS:
Each supplier is searched in one of two ways:

Live API search (stock, prices, price breaks, MOQ, lifecycle status, part type, photos and datasheets):
You need a free API key from each one - see GETTING YOUR FREE API KEYS below.

  • Mouser
  • DigiKey
  • Farnell (UK) - element14
  • CPC (UK) - same key as Farnell
  • Newark (USA) - same key as Farnell
  • TME - no datasheet links or RoHS filter from its API

Website link (one click opens that supplier's own search results in your browser):
These have no public search API.

  • RS Components
  • Rapid Electronics
  • LCSC
  • AliExpress
  • Your own - add any other supplier in SETTINGS with its website search address.

FEATURES:

  • One search covers every selected supplier, with results arriving as each one answers.
  • Keyword or Manufacturer Part Number search.
  • ADVANCED SEARCH pop-up (Ctrl+F) - exact part number, look up a supplier order code across every supplier, in stock / RoHS / active parts only, manufacturer, description words, price at the quantity you need, and max price.
  • TYPES filtering - see every kind of part found and untick the ones you don't need.
  • PRICES IN GBP (or your own currency) - every supplier's price converted at the European Central Bank's daily rates, so you can compare and sort properly.
  • LOAD MORE - fetch the next batch from any supplier that has more (e.g. Hits 50 / 312).
  • Part photos - thumbnails in the grid, click for a bigger view.
  • TYPE and DATASHEET columns - the kind of part in each supplier's own words, and a one-click link to the datasheet.
  • Click the supplier part number to open the product page; right-click to copy part numbers.
  • Sort by any column, IN STOCK ONLY, a live text FILTER, remove parts you don't want, and untick a supplier to hide its results instantly.
  • Row numbers (#) that stay put, so you can note a part and find it again.
  • Total parts count in the status bar.
  • Export to CSV for Excel.
  • Four colour themes (Light, Soft grey, Dark grey and Dark), remembered window size and column layout, tooltips on everything, built-in Help, plus a separate API Help for getting your keys.

INSTALLATION INSTRUCTIONS:

Fresh Installation of WinPartsFinder:
1. Download and run the .msi installer - WinPartsFinder.msi
2. The program is installed at: C:\Program Files (x86)\IanJ\WinPartsFinder\WinPartsFinder.exe
3. Desktop and Start menu shortcuts are created to run the app.
4. Run the app, click SETTINGS and paste in your API keys (see below).
5. Your settings and keys are stored in C:\Users\[username]\AppData\Roaming\WinPartsFinder\settings.json

Updating WinPartsFinder app:
1. Install using the newer .msi installer as above. It replaces the old version and does not touch your settings or keys.

Moving WinPartsFinder to a new PC:
1. Install WinPartsFinder on the new PC.
2. Copy your settings.json from C:\Users\[username]\AppData\Roaming\WinPartsFinder\ on the old PC to the same folder on the new PC.
3. Re-enter your API keys in SETTINGS - for security they are encrypted for your Windows user on that PC only, so they can't be read on another PC. Everything else (suppliers, layout, theme etc.) carries over.

Installation Notes:
1. Requires .NET Framework 4.8, which is already part of Windows 10 & 11. The installer checks for it.
2. Uninstall from Windows Settings > Apps. Your settings.json is left in place in case you reinstall; delete the WinPartsFinder folder in AppData\Roaming if you want it gone too.
3. The installer isn't code-signed, so Windows SmartScreen may say "Windows protected your PC" - click More info > Run anyway.

GETTING YOUR FREE API KEYS:
Each user needs their own keys - they're free. The GET A KEY links in SETTINGS open each sign-up page, and the API HELP button in SETTINGS has these same steps in a window you can keep open while you paste the keys in. Without keys, those suppliers still work as website links.

MOUSER:
1. Go to the Mouser API Hub - https://www.mouser.co.uk/api-hub/ and sign up for the Search API.
2. Paste the key into SETTINGS > Mouser Search API key.

DIGIKEY:
1. Sign in at https://developer.digikey.com/ and create an Organization.
2. Add a Production App. Select ProductInformation V4 (leave the others as None). The OAuth Callback can be https://localhost - it isn't used.
3. Open the app and copy its Client ID and Client Secret into SETTINGS.
4. Choose your DigiKey site and currency, e.g. UK / GBP, or NZ / NZD.

ELEMENT14 (FARNELL, CPC & NEWARK):
1. Register an application at https://partner.element14.com/
2. Tick Issue a new key for Product Search API. The Basic tier is plenty for one person.
3. Paste the key into SETTINGS > element14 API key - one key works for Farnell, CPC and Newark.
4. Choose your FARNELL STORE - any of 40 element14 country stores (UK, Ireland, Europe, Australia, New Zealand, Singapore, India...), each with its own stock, prices and currency.

TME: (two websites are involved)
1. At https://developers.tme.eu/en sign up, enter an application name (e.g. WinPartsFinder) and click Create application. This gives you the Application secret.
2. In another tab, log in to your normal shop account at https://www.tme.eu (not the developers site) - create a free customer account if you don't have one. Click User panel > Applications > Register new app and copy the temporary token it shows.
3. Back on developers.tme.eu, paste it into Temporary token, choose Key purpose To compare distributors offer, click Generate new private key, then Show private keys.
4. Paste that Token and the Application secret into SETTINGS, and choose the TME country and currency (GB / GBP to start with).

Free API tiers allow roughly 1000 calls a day per supplier; each search, and each Load More, is one call (a TME search uses a few).

INSTRUCTIONS / NOTES FOR USE (basic only):
The built-in HELP button explains everything in more detail, and hovering over any control shows a tip.

SEARCHING:
Type a part number or keywords (e.g. LM358 or 10nF 50V 0603) and press Enter or SEARCH.
Keyword searches descriptions and part numbers. Manufacturer part no. looks for parts whose manufacturer part number starts with what you typed.
MAX/SUPP. is how many results to fetch from each supplier per search (up to 50).
CANCEL stops any searches still running. Click the arrow on the Search box to see your last 30 searches - click one to put it back in the box. Matching previous searches are also suggested as you type.

ADVANCED SEARCH:
Click ADVANCED next to Search, or press Ctrl+F. The window remembers your choices while the app is open, results go into the same grid, and the status bar lists the options used.
Search type: Keyword, Manufacturer part no. (starts with), Exact manufacturer part no., or Supplier order code - e.g. a Farnell or Mouser order number: it finds that part, then searches every other supplier for the same part.
In stock only and RoHS only are applied by the suppliers themselves. Active parts only, Manufacturer name contains, Manufacturer part no. contains and Description contains are applied to what comes back. Only remember part of a number? Leave Search for blank and put e.g. 931G in Manufacturer part no. contains and switch in Description contains - they're searched for together (DigiKey and Mouser can find part of a number).
Quantity needed shows the price each at that quantity (the PRICE column becomes e.g. PRICE (100)) and hides parts with a higher minimum order. Max price each hides anything dearer.

SUPPLIER LIST:
Tick the suppliers to search. MODE shows how each is searched (API, API (no key) or Web link), and STATUS, HITS and TIME show how each search went - hover over a supplier to see any error.
After a search, untick a supplier to hide its rows, and tick it again to bring them back. Ticking a supplier that wasn't part of the search searches just that supplier straight away.
Double-click or right-click a supplier to open the same search on its website.

RESULTS:
# numbers each part so you can note it and find it again - numbers never change until the next search.
STOCK is green when in stock; parts with no stock are greyed out. PRICE (1) is the price each at the lowest price break, and PRICE BREAKS lists them all.
TYPE is the kind of part in the supplier's own words. DATASHEET opens the datasheet with one click, and is blank when the supplier doesn't provide one.
Blue italic rows are website links for suppliers without an API - click them to see results on that website.
Click a SUPPLIER PART NO. to open the product page. Click a photo for a bigger view.
Click any column header to sort; click SUPPLIER to group each supplier's rows together, or # for the original order. Column widths, order and window size are remembered.

LOAD MORE:
When a supplier has more matches than it sent, its HITS shows e.g. 50 / 312. LOAD MORE fetches the next batch from every ticked supplier that has more, or right-click a supplier to load more from just that one. New rows are added at the end and selected so you can spot them.

RIGHT-CLICK MENU:
Open the product page or datasheet, copy the manufacturer or supplier part number, or copy rows ready to paste into Excel.
REMOVE FROM RESULTS (or the Delete key) hides parts you don't want - select several with Ctrl/Shift-click. RESTORE REMOVED ROWS brings them all back.

FILTER / EXPORT:
IN STOCK ONLY hides parts with no stock. FILTER narrows the results as you type (supplier, part numbers, manufacturer, type and description).
TOTAL PARTS in the bottom right shows how many parts were found, and how many are showing when some are hidden.
EXPORT CSV saves the rows shown, with product and datasheet links, to a file that opens in Excel.

TYPES FILTERING:
After a search, click Types… to see every kind of part found, such as Analogue to Digital Converter, Evaluation Kit or Flip-Flops, with how many came from each supplier. Untick the ones you don't need, and they disappear from the results instantly.

SETTINGS:
API keys grouped by supplier (with GET A KEY links and an API HELP window), DigiKey site & currency, Farnell store (country), TME country & currency.
Website search addresses for each supplier, plus ADD SUPPLIER / DELETE SUPPLIER for your own.
Show part photos, Theme (Light, Soft grey, Dark grey or Dark), Reset URLs, Reset main window layout.

COMMON & NOT SO COMMON ISSUES:

ISSUE 1:
A supplier shows Error:
Hover over the supplier in the list to see why.
HTTP 401 - the key or secret is wrong. Paste it again in SETTINGS, checking for spaces at either end.
HTTP 403 - the key isn't active yet, or (DigiKey) ProductInformation V4 isn't selected on your DigiKey app.
Timeout - the supplier was slow to answer, search again.

ISSUE 2:
Fewer results than expected:
Check IN STOCK ONLY isn't ticked, FILTER is empty and no types are hidden (the TYPES button shows e.g. "Types (3 hidden)") - TOTAL PARTS in the bottom right shows e.g. "Total parts = 14 (showing 1)" when something is hiding rows.
After an Advanced search, the status bar shows how many parts its filters left out, e.g. "(12 left out)".

ISSUE 3:
Mouser rows have no photo:
Mouser doesn't allow its photos to be downloaded by apps, so Mouser rows borrow a photo of the same part from DigiKey or Farnell when one was found.

ISSUE 4:
Prices in different currencies:
Each row shows its own currency (CUR column). Farnell is in the currency of the store you choose in SETTINGS (GBP for the UK store), CPC in GBP, Newark in USD, TME and DigiKey in the currencies you choose in SETTINGS, and Mouser in the currency of the account your key was registered with. Tick PRICES IN GBP (choose the currency in SETTINGS) to see every price converted at the European Central Bank's daily rates - converted prices are purple and approximate; hover over one to see the supplier's own price.

ISSUE 5:
Window off-screen or layout in a mess:
Use SETTINGS > RESET MAIN WINDOW LAYOUT and click OK.

ISSUE 6:
New apps are sometimes flagged by Windows anti-virus scans or SmartScreen as they aren't code-signed. If it happens to you then please let me know and I will contact the anti-virus company involved.
